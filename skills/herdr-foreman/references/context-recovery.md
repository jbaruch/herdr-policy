# Herdr Context Recovery

## Preserve

- Retain current ownership, operator holds, unknown sends, reports and the active goal.
- This context grants no dispatch, reset, progression or release authority.
- An unavailable controller never converts unresolved team work into ordinary work.

## Restore

- Restore the same controller and native identity through its existing owner.
- Never create a replacement foreman, erase owner stores or scan history for a new start.
- Read only the bounded current-owner exception needed for recovery.
- A policy upgrade requires its verified authority handoff.

## Continue

- Retain the Stop obligation until its actual owner proves coverage, explicit pause or completion.
