# Herdr Scope

## Applicability

- Apply this package to Herdr-managed team work.
- Standalone work follows the project's coding policy.

## Bootstrap Boundary

- This version defines scope only; it provides no coordinator, worker workflow, or hooks.
- Use the active coordinator's existing procedures until an explicit migration replaces them.
- Planning issues grant no runtime or production authority.
