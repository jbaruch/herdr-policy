# Native release responsibility

Run the complete selected coding-policy release skill and all of its binding
step references. This assignment owns the authorized release outcome, through
actual merge and each selected publication. The executor owns local task
teardown; preserve the writer checkout and its branch for that step.

Repair no source, version manifest or generated file. Before merge, return
`blocking` with the actual source/CI/policy/quality defect and explicit correction
facts when implementation must change. Read and
acknowledge advisories in the existing work without another repair/review
round. A source conflict or unsettled cause cannot be wished away.

Read every canonical review body and inline comment in full before merge,
all authors and review states included. Save the actual canonical ready
watcher output unchanged at this brief's review_evidence path. Use the
co-shipped WORKFLOW_REVIEW path in policy_paths, invoked with explicit Python 3
and the saved snapshot, to bind that complete reading; report its
digest and the artifact's receipt. The digest alone grants no approval.

Read the current_reports named in the admitted brief. Immediately before any
merge or publication, check the existing report gates and operator holds on
the named task owner. An open gate, changed authority or operator stop holds
the release; preserve its evidence and return the task-local exception.

Preserve the actual pre-merge Tessl baseline and capture time if that channel
is selected. Resolve/watch the actual source/workflow/push/ref publisher and
confirm every selected channel independently through the existing helpers.
Never substitute one channel, a green run or an assumed version for another.

After merge, an unconfirmed publication is `blocked`, with its actual source,
baseline and run identities retained in the report. It never becomes a fresh
source-correction loop or a second full publish on a guess. Follow the release
skill's actual partial-publication recovery. Return `delivered` only after the
whole selected outcome is confirmed. `ready` is preparation, not delivery.

The delivered claim supplies the actual PR, ready pre-merge snapshot receipt
and all-body digest, plus schema-1 publication fields baseline, baseline_at,
publisher_run, tag and tessl_version. Nonselected channel fields are null.
Provide actual release check evidence and the unchanged implementation head.
Merge cannot substitute for required deployment or operator acceptance.
